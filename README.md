## Installation
- Create virtual environment at project level with folder name .venv
```bash
python -m venv .venv
```
- Synchronize Poetry
```bash
poetry sync
```

# Start API Server
- Open new CMD Terminal
- Run below cmd
```bat
start_server
```

## Start MCP Server
- Open new CMD Terminal
- Activate the virtual environemnt
- Run below cmd
```bash 
python -m server.mcp
```
